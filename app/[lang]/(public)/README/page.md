# README

README on ainejärjestömme pieni ja pippurinen opiskelijalehti. README käsittelee aiheita laajalla skaalalla, esimerkiksi opiskeluun, tietojenkäsittelytieteeseen, sekä vapaa-aikaan liittyen. Julkaisemme ajankohtaisia artikkeleita järjestön ja laitoksen tuoreimmista kuulumisista, sekä kevyempää sisältöä. Kaikki vanhat ja tuoreemmatkin numerot ovat luettavissa PDF:nä tämän sivun alalaidassa. Lisää tekstejä löytyy [blogistamme](https://blog.tko-aly.fi).

Lehti kaipaa jatkuvasti uusia ideoita ja kirjoittajia – kaikki innolla mukaan! Toimitukseen on hämmästyttävän helppo liittyä, päätoimittajaan saa yhteyden lähettämällä sähköpostia osoitteeseen paatoimittaja ät tko-aly.fi.

#### Briefly in English

README is the small but mighty magazine of our subject organization. README deals with topics on a wide scale, for example related to studying, computer science, and free time. We publish articles about the organization's and University’s latest news, as well as lighter content. All issues can be read as a PDF at the bottom of this page. More texts can be found on [our blog](https://blog.tko-aly.fi)

The magazine is constantly in need of new ideas and writers - everyone is welcome! It is amazingly easy to join the editor, you can contact the editor-in-chief by sending an e-mail to the address paatoimittaja ät tko-aly.fi.
